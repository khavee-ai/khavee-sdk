| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02 | Tampering | OpenAILLMAdapter JSON.parse of tool_call arguments | mitigate | Parse occurs inside the adapter; ToolExecutor (called later by orchestrator) normalizes any tool handler throw to {success:false,message} — malformed args cannot crash the session |
| T-02-03 | Information Disclosure | Bearer token in Authorization header | mitigate | Token passed via header (not URL), matching STTClient/ChatClient/TTSPlayer convention; no API key embedded in browser per backend-proxy constraint |
| T-02-04 | Denial of Service | Oversized audio blob to STT proxy | accept | MAX_WAV_BYTES (24MB) guard preserved inside the wrapped AudioRecorder; VAD adapter does not bypass it |
| T-02-05 | Tampering | Untrusted proxy response shape | mitigate | Adapters validate response (ok status check, text/transcript presence) and throw a normalized Error on malformed/non-2xx responses |
