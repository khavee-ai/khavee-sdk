<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VAD utterance → orchestrator | User audio triggers turns; rapid barge-in can race state mutations |
| LLM tool_calls → ToolExecutor | Tool names/args from LLM output dispatched in-process |
| provider rejection → onError | Untrusted error values (strings, vendor objects) cross into the session |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Denial of Service | Runaway agentic tool-calling loop | mitigate | MAX_TOOL_ROUNDS=5 cap (D-05); exceeding throws a normalized Error and ends the turn at "ready" rather than looping/spending forever |
| T-02-07 | Tampering | Superseded (aborted) turn mutating shared conversation/messages state | mitigate | signal.aborted guard after every await boundary discards stale results (Pitfall 3) — prevents out-of-order conversation corruption |
| T-02-08 | Repudiation | Provider throwing a non-Error value crashing the session | mitigate | error instanceof Error ? error : new Error(String(error)) normalization at every await boundary (ORCH-05); session stays alive at "ready" |
| T-02-09 | Elevation of Privilege | Tool handler throwing inside the loop | accept | ToolExecutor already normalizes handler throws to {success:false,message} (CORE-05) — a misbehaving tool cannot escalate or crash the loop |
</threat_model>
