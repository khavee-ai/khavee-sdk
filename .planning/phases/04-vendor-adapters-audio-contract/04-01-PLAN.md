## Objective

Create a Next.js demo page at `/generic-demo` that proves `GenericPipelineProvider` works with a real non-OpenAI STT backend (Thonburian Whisper) by implementing the STT adapter as demo-local code (not in the SDK package). Covers requirement ADPT-01.

## Context

From `04-CONTEXT.md` and `04-RESEARCH.md`:
- `thonburian-stt` service runs at `http://localhost:8001`, expects `POST /transcribe` with multipart field name `file`, returns `{"text": string}`
- STTProvider contract is in `packages/core/src/types/pipeline.ts`
- OpenAI adapters at `packages/providers/generic-stt-tts/src/adapters/` provide the pattern to follow
- VAD utterance encoding is handled upstream by MicVAD's `encodeWAV()` (16kHz/mono/float32 WAV)

## Tasks

**Dependencies:** None

Create a Next.js page component that:

**Verification:**
- Page renders at `/generic-demo` without errors
- No TypeScript errors from `npx tsc --noEmit`
- Connect/discover buttons work (even if pipeline doesn't fully function yet)

### Task 2: Implement Thonburian STT adapter in demo app

**File:** `src/app/generic-demo/adapters/ThonburianSTTAdapter.ts` (new)
**Dependencies:** Task 1 (demo page exists)

Create the STT adapter class that:
- Implements `STTProvider` interface from `@khaveeai/core`
- Constructor accepts `{ baseUrl?: string }` config, defaults to `http://localhost:8001`
- Has `supportsStreaming = false`, `supportsRejection = false` capability flags
- `transcribe(audio: Blob, opts?: { language?: string }): Promise<STTResult>` method:
  - Creates `FormData` appends `audio` blob as field name `file` (note: not `"audio"` - that's the thonburian-stt convention from CONTEXT.md D-01)
  - Uses `fetch()` with `AbortSignal.any()` combining 60s timeout + `opts?.signal`
  - POSTs to `${baseUrl}/transcribe`
  - Returns `{ text: response.text }` (STTResult shape, omitting `rejected` field per CONTEXT.md D-06 since thonburian-stt doesn't support rejection)
  - Normalizes errors via `error instanceof Error ? error : new Error(String(error))`
- Silently ignores `opts?.language` (thonburian-stt always transcribes as Thai per CONTEXT.md D-04)

**Verification:**
- TypeScript compiles without errors
- Manual smoke test: if thonburian-stt service is running, a real WAV file POST returns the expected `{text}` response
