## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SDK adapter → thonburian-stt HTTP | Adapter sends a WAV blob over localhost HTTP to an unauthenticated local FastAPI service. Per D-01 there is no auth — these are local-only demo services with nothing to protect; the boundary is not exposed to a network/customer trust edge. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of Service | thonburian-stt /transcribe (oversized/hung response) | mitigate | `AbortSignal.timeout(this.timeoutMs)` default 60s (D-03) bounds a hung/crashed backend; the timeout-triggered abort normalizes through `error instanceof Error ? ...` like any other failure. |
| T-04-02 | Denial of Service | Oversized audio blob upload | accept | Upstream `AudioRecorder` already enforces `MAX_WAV_BYTES = 24_000_000` before any blob reaches this adapter (RESEARCH Security Domain); adapter does not re-guard. Documented as a one-line note in the class doc comment. |
| T-04-03 | Information Disclosure | Unexpected non-JSON / wrong content-type response | mitigate | Non-2xx responses throw with the status + body text before any JSON parse; a 200-with-bad-JSON surfaces as a normalized Error via the try/catch, not a crash. |
| T-04-04 | Tampering | SSRF via developer-overridden `baseUrl` | accept | `baseUrl` is a developer-supplied constructor config (same trust assumption as OpenAI adapters' `endpoint`), not end-user input — out of scope for this phase's threat model (RESEARCH Security Domain). |

No npm/pip/cargo installs in this plan (zero new dependencies — all APIs are native Node/browser globals per RESEARCH). No package-legitimacy checkpoint required.
