<objective>
Build the config-source strategy seam (ARCH-01): a two-method `ConfigSourceInterface` and its single concrete `WpOptionsConfigSource` implementation, plus the plugin bootstrap file and Composer PSR-4 autoload map so the rest of the plugin can be autoloaded.

Purpose: This is the swappable seam that lets a future Platform-mode config source replace the WP-options source without touching the REST contract or JS bundle. It also establishes the API-key-never-leaves-server invariant by separating the public-safe `get_runtime_config()` from the server-only `get_api_key()`.

Output: `ConfigSourceInterface.php`, `WpOptionsConfigSource.php`, `khaveeai.php` (bootstrap stub), `composer.json` (autoload only, no runtime deps).
</objective>
