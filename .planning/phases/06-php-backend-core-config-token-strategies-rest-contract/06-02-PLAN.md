<objective>
Build the token-provider strategy seam (ARCH-02): a one-method `TokenProviderInterface` and its single concrete `OpenAiDirectTokenProvider`, which mints an OpenAI Realtime ephemeral token server-to-server via `wp_remote_post()`. The provider takes the API key as a parameter (never reads wp_options itself) — the DI seam that lets a future Platform-mode provider swap in. A standalone PHP harness (no WP/Composer required) proves response reshaping and failure normalization.

Purpose: This is the only component that talks to OpenAI. Getting the response reshaping (`value` → `ephemeralToken`) and the no-leaked-detail failure handling right here is what makes the REST contract in plan 03 satisfiable and abuse-safe.

Output: `TokenProviderInterface.php`, `OpenAiDirectTokenProvider.php`, `tests/token-provider-harness.php`.

TokenProviderInterface (ARCHITECTURE.md lines 134-141):
- mint_session(array $session_config, string $api_key): array
  - $session_config: shape matching OpenAIRealtimeProvider's sessionConfig (model, instructions, voice, tools, audio)
  - $api_key: resolved by ConfigSourceInterface::get_api_key(), PASSED IN — the provider never reads wp_options itself (the DI seam)
  - returns array{ephemeralToken: string, sessionId: ?string, expiresAt: ?int}

OpenAI endpoint contract (ARCHITECTURE.md Integration Points + line 221):
- POST https://api.openai.com/v1/realtime/client_secrets
- Header: Authorization: Bearer <real api key>, Content-Type: application/json
- OpenAI raw success response top-level field is `value` (the "ek_..." token); session info under `session` (may include an id). Default TTL ~1 minute.
- mint_session() MUST read $body['value'] and remap it to the `ephemeralToken` key in its OWN return array (PATTERNS.md OpenAiDirectTokenProvider section).

wp_remote_post mechanics (STACK.md "What NOT to Use" → wp_remote_post row):
- WP default HTTP timeout is only 3s — MUST pass an explicit 'timeout' => 10.
- Check is_wp_error($response) AND wp_remote_retrieve_response_code($response) for non-2xx.
