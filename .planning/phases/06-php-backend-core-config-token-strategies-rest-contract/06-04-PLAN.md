    (1) REST-01: POST with `Content-Type: application/json` and body `{"sessionConfig":{"type":"realtime"}}`; assert HTTP 200 and that the JSON response contains a `data.ephemeralToken` value beginning with `ek_` (use the `-i` flag and/or `-w '%{http_code}'`, parse with grep/jq-if-available falling back to grep).

    (4) REST-04: assert the 200 response from check (1) includes a `Cache-Control: no-store` response header (case-insensitive grep on `-i` output).
    Print PASS/FAIL per check with the observed HTTP code, and exit non-zero if any check fails. Add a header comment documenting the prerequisites: a running WP install with the plugin active and khaveeai_settings.api_key set to a real OpenAI key, and that the rate-limit transients may need clearing (`wp transient delete --all`) between runs since check (3) consumes the per-IP budget.
