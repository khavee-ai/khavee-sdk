<objective>
Close the three open items that prevented Phase 7 from passing clean verification (07-VERIFICATION.md), all without touching or replanning 07-01/02/03:

1. **CR-01 (BLOCKER, security):** The submitted `voice` value is persisted through `sanitize_text_field()` only, never validated against the 10-value `self::VOICES` allowlist the `<select>` dropdown is built from. A crafted POST persists an arbitrary string into the `voice` option, which `SessionController` later forwards into the trusted OpenAI Realtime session config unrevalidated. Fix: validate against `self::VOICES` in `sanitize_settings()`, falling back to the existing value (same convention `sanitize_api_key()` uses for masked-resave safety) or the first allowlisted default.

2. **CR-02 (WARNING, defense-in-depth):** `is_khaveeai_upload_request()` gates the `.glb`/`.vrm` content-validation filter activation on `$_GET['page']` OR `wp_get_referer()` only — both spoofable by a non-browser HTTP client. Fix: AND a verifiable plugin-issued nonce into the gate, fail-closed, so the magic-byte filter is active exactly when expected and never via a forged Referer alone. The fix MUST keep the shipped `admin_init` + Referer mechanism and MUST NOT reintroduce the `load-<hook_suffix>` approach that was empirically falsified live during 07-03's checkpoint (07-03-SUMMARY.md Deviation 2).

3. **ROADMAP.md Success Criterion 5 wording (documentation only):** Phase 7's Criterion 5 bundles a Phase-8-scope deliverable (frontend embed notice + logged-out placeholder, requiring EMBED-01..05/PERF-01, all Pending) into Phase 7's criteria. Phase 7 correctly scoped only the `is_configured()` contract (D-13) + the settings-page "not configured" banner (D-14). Fix: edit the criterion so future verifiers don't re-flag this as a Phase 7 implementation gap.

Purpose: Move Phase 7 from `gaps_found` to clean. CR-01 is the only true BLOCKER; CR-02 is defense-in-depth hardening; Gap 3 is a docs accuracy correction.
Output: Modified `SettingsPage.php` (allowlist validation + nonce gate + nonce emission), extended `settings-page-harness.php` (voice-allowlist + nonce-gate cases), corrected `ROADMAP.md` Phase 7 Criterion 5 wording.
