## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page author → rendered HTML | Shortcode/block attribute values flow into the `data-khaveeai-config` HTML attribute |
| visitor role → notice markup | Admin-only not-configured notice must never reach a non-admin's page source |
| render path → page assets | Asset enqueue is the PERF-01 boundary — must trigger only on real render |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Tampering | reflected XSS via attribute values in data-khaveeai-config | mitigate | `esc_attr( wp_json_encode( $public_safe ) )` exactly; public_safe whitelists keys (RESEARCH Security Domain reflected-XSS row) |
| T-08-06 | Information Disclosure | api key leaking into mount-point JSON | mitigate | `public_safe()` whitelist excludes the key; harness case asserts no key sentinel in output; get_api_key never called in AvatarRenderer |
| T-08-07 | Information Disclosure | admin-only notice exposed to logged-out visitors | mitigate | D-06 notice rendered only inside `current_user_can('manage_options')` branch — markup absent (not CSS-hidden) for others (ASVS V4) |
| T-08-08 | Denial of Service | bundle enqueued site-wide degrading every page | mitigate | Enqueue called only from render() with `wp_script_is` idempotency guard; no blanket `wp_enqueue_scripts` hook (PERF-01) |
</threat_model>
