## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous client → REST route | The bundle (any visitor) POSTs instanceOverrides; this is untrusted input crossing into the token-mint flow that ultimately reaches OpenAI |
| validated config → OpenAI | Only allowlist/cap/existence-validated values may reach mint_session() |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-09 | Tampering | voice override jailbreak (arbitrary string to OpenAI) | mitigate | Validate FIRST with `in_array(..., self::ALLOWED_VOICES, true)`; non-allowlisted → global voice; harness asserts malicious value rejected (Pitfall 4, CR-01 precedent) |
| T-08-10 | Tampering | prompt injection via instructions override | accept | Length cap reduces blast radius; full content-filtering out of scope — a page author editing their own shortcode already has author-tier trust over their own page (RESEARCH Security Domain, accepted residual) |
| T-08-11 | Information Disclosure | avatar attachment-ID enumeration via override param | mitigate | `get_post($id)` + `post_type === 'attachment'` + expected MIME check; fallback to global, no "not found" detail echoed |
| T-08-12 | Information Disclosure | rejection-reason detail aiding probing | mitigate | Silent fallback only; no distinct error code/message for rejected overrides (existing generic-error convention) |
| T-08-13 | Repudiation | regression silently re-opening D-07 gap | mitigate | No-override regression harness case asserts Phase 6 global-forced output is byte-for-byte unchanged |
