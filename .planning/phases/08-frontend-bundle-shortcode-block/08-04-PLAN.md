<objective>
Add the Gutenberg block half of the embed: a `khaveeai/avatar` block whose inspector controls mirror the settings page (voice select, instructions textarea, wp.media avatar picker), that renders through the SAME shared `AvatarRenderer::render()` as the shortcode (EMBED-03 parity / EMBED-04), and whose editor preview uses `ServerSideRender` + a PHP `render_callback` so the live SPA, mic prompt, and token mint NEVER fire while editing (EMBED-05). The front-end bundle is enqueued via the shared render path (AssetManager), deliberately NOT via `block.json` `viewScript` (the documented dynamic-block bug, RESEARCH Pitfall 1).

Purpose: completes the two-embed-method surface, with the editor/front-end split done correctly on the first try (an "expensive to reverse once shipped" choice per RESEARCH).
Output: `block.json`, `AvatarBlock.php`, `assets/editor.js`, a `wordpress-plugin/package.json` for the @wordpress/scripts editor build, and Plugin.php wiring.
</objective>
