# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [x] CONSTRAINT: dangerouslySetInnerHTML:{__html:''} is NOT a safe way to stop React 18 from clobbering a React 19-managed child — it causes React 18 to blank innerHTML on first render, destroying the R3F canvas. Mitigation: use empty virtual children (no child createElement call) instead. Already applied (commit 2078a83).
- [ ] CONSTRAINT: enqueue_block_editor_assets loads scripts in the PARENT editor document, but WordPress 6.1+ renders the block canvas inside an isolated `<iframe>`. A preview bundle loaded in the parent cannot see iframe DOM. Mitigation: register the script and reference it by handle in block.json `editorScript` array so it loads inside the iframe. Already applied (commit 5a4d5ec) — **BUT NOT YET VERIFIED by the user.**

**Do not proceed until both boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| dangerouslySetInnerHTML as a reconciliation barrier | Plan 09-07 prescribed `dangerouslySetInnerHTML:{__html:''}` to stop Gutenberg clobbering React 19 output. It instead made React 18 blank the container, killing the canvas. | blocking | Empty virtual children (no child element) — React 18's reconciler only manages fiber-tree nodes, never externally-injected DOM children. Commit 2078a83. |
| Loading editor-preview scripts via enqueue_block_editor_assets | The hook loads scripts in the parent editor document; the block canvas is an iframe. Script's MutationObserver sees an empty document. | blocking | Register script by handle + list it in block.json `editorScript` array → loads inside iframe. Commit 5a4d5ec. |
