## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Author → block attributes (via setAttributes) | Author-supplied values from the inspector controls cross into persisted block markup via Gutenberg's setAttributes |
| editor.js → preview bundle (via data-khaveeai-preview-config JSON) | The 17 attributes + previewTalking flag cross from editor.js's createElement tree into the preview-bundle mount point as serialized JSON |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-01 | Tampering / XSS | editor.js → data-khaveeai-preview-config JSON | mitigate | The JSON is built from Gutenberg-controlled block attributes (already type-validated against block.json schema — number/boolean/string). The preview bundle (Plan 09-03) JSON.parses it into a typed KhaveeAvatarConfig. The author cannot inject arbitrary HTML/CSS via these controls — the values are color hex strings, preset enum strings, numeric slider values, and a Media Library attachment ID (cast int). No innerHTML path is introduced. |
| T-09-02-02 | Tampering | Background-image picker (MediaUpload) | mitigate | Background image is selected via WP core's MediaUpload component (the same flow avatar already uses), which returns a Media Library attachment ID — never a free-form URL. The ID is validated as `> 0` and resolved via wp_get_attachment_url() in AvatarBlock.php (Plan 09-01). No SSRF/path-traversal vector. |
| T-09-02-03 | Information Disclosure | editor.js import graph | mitigate | editor.js imports NOTHING from @khaveeai/* (header comment documents this; grep enforced). The preview bundle is separately enqueued (Plan 09-06) and structurally isolated (Plan 09-01 build.mjs grep assertion). No API key, no token-mint code, no mic access reachable from editor.js. |
| T-09-02-04 | Denial of Service | Undo-stack spam (Pitfall 4) | mitigate | RangeControl onChange is debounced (~50ms) or committed on pointer-up — prevents 50+ undo entries per slider drag. The live preview-config JSON uses the un-debounced ref value so the preview stays reactive without spamming the persistence layer. |
| T-09-02-SC | Tampering | npm installs | accept | Plan installs zero new packages — RangeControl/ToggleControl/ColorPalette/MediaUpload are all part of @wordpress/components (already in wordpress-plugin/package.json, externalized to window.wp.* by webpack). No supply-chain risk. |
</threat_model>
