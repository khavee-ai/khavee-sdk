<objective>
Create the `set_gesture` LLM tool-schema factory (`toolGesture`) in `@khaveeai/core` and add it to the package barrel export, so a consuming app can register it into any `RealtimeConfig.tools` and have the LLM emit `nod`/`shake`/`none` gesture hints through normal tool-calling (GEST-01).

Purpose: GEST-01 requires the LLM to emit gesture hints via tool-calling with no separate classification call and no keyword/regex matching. RESEARCH confirmed `toolAnimate` — the shape to mirror — is currently unexported from `packages/core/src/index.ts`, so a naive copy would leave `toolGesture` unimportable end-to-end. This plan fixes the packaging gap that would otherwise make GEST-01 silently unimplementable.

Output: `packages/core/src/tools/gesture.ts` (new), barrel export in `index.ts`, and a unit test asserting shape + enum + `RealtimeTool` conformance.
</objective>
