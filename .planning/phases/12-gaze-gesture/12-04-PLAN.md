<objective>
Thread the gesture-hint signal from app code into the animation layer, and integrate both the gaze and gesture procedural systems into the shared `useAnimationController`. This is the wiring wave that makes GAZE-01/02 and GEST-01/02 actually run every frame.

Purpose: The LLM tool's `execute` callback is supplied by the consuming app (typically at provider-construction time, OUTSIDE the React tree — RESEARCH Pitfall 3), so — unlike `currentVolume`'s intentionally-internal-only setter — `setGestureHint` MUST be public on `useKhavee()`'s return so app code can write to it. The controller then reads `gestureHint` + the R3F `camera` and steps gaze (continuous) and gesture (triggered) in a fixed, appended composition order per the file's "extend this list, never reorder" convention.

Output: `KhaveeProvider.tsx` (gestureHint field + public validated setGestureHint), `AnimationStateEngine.ts` (new params + hook instantiation + composition steps 10/11), and controller integration tests.
</objective>
