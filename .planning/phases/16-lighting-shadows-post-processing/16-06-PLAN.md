<decisions>
- **A new page, not a change to `mtoon-spike`.** The spike MANIFEST records that `mtoon-spike` was
  graduated into a permanent regression fixture and that later work gets its own page. This harness
  imports `measureCanvas` from it read-only and changes nothing there.
- **The gate is a same-harness delta, and no absolute figure appears anywhere in this plan.**
  Spike 005's finding: `0.3041` was measured on a different render path, framing, ambient and
  `materialPreset`, and is not portable in either direction. The page therefore never displays a
  target number — it displays two rows measured in one session and their difference.
- **"Legacy" means khavee-app's production rig, reproduced exactly.** `autoLighting={false}` plus a
  hand-rolled `<ambientLight intensity={0.7} />` and `<directionalLight position={[10,10,5]} castShadow />`
  with no shadow tuning. `0.7`, not `0.6` — verified in spike 005's `rigs.tsx`, which warns that
  guessing this wrong silently invalidates the comparison.
- **Measurement is blocked while a backdrop is mounted, in the UI, not in the instructions.**
  `measureCanvas` skips pixels with alpha below 128, so on a transparent canvas it measures avatar
  pixels — but with a backdrop covering the frame it measures the wallpaper and returns a confident
  wrong number. The Measure control is disabled whenever a background is active, with the reason
  shown on screen. A note in a README would not survive the first hurried session.
- **The harness carries its own reproduction check.** Spike 005's requirement: the only reason its
  throttled-tab artifact was caught is that the sweep contained a row whose value was already known.
  Here, measuring the same configuration twice in a session must reproduce, and the panel shows the
  delta between repeat measurements of an identical configuration. A large delta means the
  measurement is untrustworthy, whatever the numbers say.
- **Tab visibility is displayed, not assumed.** The panel shows `document.visibilityState` and an
  explicit warning when it is not `"visible"`, because a hidden tab throttles `requestAnimationFrame`
  to roughly 1Hz and returns an empty WebGL buffer — the exact failure that produced spike 004's
  false "2570 ms/frame" and spike 005's all-null sample run.
- **No dev server is started by the executor.** The developer runs their own server. Task 1 verifies
  with `tsc`/lint only; Tasks 2 and 3 are human checkpoints performed against the developer's
  already-running server.
- **Fixtures are generated in code, not committed as binaries.** `lighting-spike/testTexture.ts`
  already generates procedural fixtures; this page graduates that approach so no image assets enter
  the repo and the three aspect ratios are exact by construction.
</decisions>
