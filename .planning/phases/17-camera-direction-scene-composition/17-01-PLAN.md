    **Main component `AvatarCamera`:**

    Destructure props with defaults: `preset = "bust-shot"`, `orbit = "locked"`, `drift = true`, `reframe = true`.

    Refs:
    - `controlsRef = useRef<CameraControls>(null)` — drei CameraControls instance
    - `noise3DRef = useRef(createNoise3D())` — create noise function once, reuse
    - `driftTimeRef = useRef(0)` — accumulated time for noise sampling
    - `isUserOrbitingRef = useRef(false)` — flag to pause drift/reframe during user interaction
    - `reframeDistanceRef = useRef(1)` — current interpolated distance multiplier for reframing
    - `initialSetDone = useRef(false)` — guard to prevent transition on first mount

    **useEffect: orbit mode configuration** (watches `[orbit, preset]`):
    - Guard `if (!controlsRef.current) return`
    - Per D-05:
      - `"locked"`: disable all mouseButtons and touches (set to 0)
      - `"constrained"`: enable rotate+dolly, apply CONSTRAINED_RANGES for current preset
      - `"free"`: enable all controls, reset constraints to unclamped defaults
    - CameraControls action constants: `CameraControls.ACTION.ROTATE = 1`, `CameraControls.ACTION.DOLLY = 16`, `CameraControls.ACTION.TRUCK = 2`

    **useEffect: preset transition** (watches `[resolved.position, resolved.target]`):
    - Guard `if (!controlsRef.current) return`
    - If `initialSetDone.current` is false, call `setLookAt` with `enableTransition=false` (no animation on mount), then set flag true
    - Otherwise, call `controlsRef.current.setLookAt(pos[0], pos[1], pos[2], tgt[0], tgt[1], tgt[2], true)` for smooth transition per D-06

    **useEffect: FOV** (watches `[resolved.fov]`):
    - Set `camera.fov = resolved.fov`, call `camera.updateProjectionMatrix()`
    - Cast camera to PerspectiveCamera if needed: `(camera as THREE.PerspectiveCamera)`

    **CameraControls event callbacks:**
    - `handleControlStart = useRef(() => { isUserOrbitingRef.current = true })` — per D-08 drift pauses during orbit
    - `handleControlEnd = useRef(() => { isUserOrbitingRef.current = false })` — per D-08 drift resumes after orbit
    - Wire these via `useEffect` on controlsRef: `controlsRef.current.addEventListener('controlstart', ...)` and `controlend`
    - Clean up in return function

    **useFrame (priority 1 — run after CameraControls' default-priority update):**
    Apply drift and reframing as post-CameraControls camera adjustments.

    Per-frame body:
    1. Guard: `if (!controlsRef.current) return`
    2. **Drift** (if `drift` is true and `!isUserOrbitingRef.current`):
       - Advance `driftTimeRef.current += delta`
       - Sample noise: `t = driftTimeRef.current * DRIFT_FREQUENCY`
       - Position deltas: `dx = noise3D(t, 0, 0) * DRIFT_POSITION_AMPLITUDE`, `dy = noise3D(t, 100, 0) * DRIFT_POSITION_AMPLITUDE`, `dz = noise3D(t, 200, 0) * DRIFT_POSITION_AMPLITUDE`
       - Target deltas: `dtx = noise3D(t, 300, 0) * DRIFT_TARGET_AMPLITUDE`, `dty = noise3D(t, 400, 0) * DRIFT_TARGET_AMPLITUDE`, `dtz = noise3D(t, 500, 0) * DRIFT_TARGET_AMPLITUDE`
       - Apply directly to camera.position and recompute lookAt on the camera (not through CameraControls — CameraControls will reset next frame, which is the desired behaviour for drift as a transient per-frame delta)
       - Use scratch vectors: `camera.position.add(_scratchPos.set(dx, dy, dz))`
       - For the target drift, get CameraControls' current target via `controlsRef.current.getTarget(_scratchTarget)`, add target deltas, then set camera lookAt: `camera.lookAt(_scratchTarget)`
    3. **Reframe** (if `reframe` is true and `!isUserOrbitingRef.current`):
       - Compute target multiplier: `chatStatus === "speaking" ? REFRAME_SPEAKING_MULTIPLIER : 1.0`
       - Lerp: `reframeDistanceRef.current = THREE.MathUtils.lerp(reframeDistanceRef.current, targetMult, 1 - Math.exp(-delta * REFRAME_LERP_SPEED))`
       - If multiplier is meaningfully different from 1 (abs > 0.001):
         - Get current CameraControls distance via `controlsRef.current.distance`
         - Compute base distance from preset: magnitude of `(resolved.position - resolved.target)`
         - Compute desired distance: `baseDistance * reframeDistanceRef.current`
         - Apply: `controlsRef.current.dolly(currentDistance - desiredDistance, false)` (false = no built-in transition, we are lerping manually)

    **Return JSX:**
    - `<CameraControls ref={controlsRef} makeDefault />` — makeDefault ensures this camera is R3F's active camera
