  <what-built>AvatarCamera component (Plan 17-01) and the camera-demo harness page (Task 1 above). The component delivers three framing presets, three orbit modes, procedural handheld drift, and chatStatus-driven dolly reframing.</what-built>
  <how-to-verify>
    Start the dev server and navigate to http://localhost:3000/camera-demo.

    **1. Preset Framing (CAM-02, CAM-03):**
    - Select "bust-shot" — avatar should be framed from roughly shoulders up, face clearly visible
    - Select "medium-close-up" — slightly wider framing showing more of upper torso
    - Select "full-body" — full avatar visible head to feet
    - PASS if: All three presets frame the avatar deliberately, face is visible in all, no clipping
    - FAIL if: Any preset cuts off the avatar's face, frames the floor, or shows an unflattering angle

    **2. Preset Transitions (CAM-02):**
    - Switch between presets rapidly (bust -> full -> MCU -> bust)
    - PASS if: Transitions animate smoothly with an eased curve (not instant cut, not sluggish)
    - FAIL if: Camera jumps instantly, or animation is mechanical/linear, or takes more than 2s

    **3. Handheld Drift (CAM-05):**
    - With drift enabled (default), observe the camera for 10+ seconds
    - PASS if: Camera shows subtle organic motion — not perfectly static, reads as a real camera
    - Then uncheck drift toggle — observe again
    - PASS if: Camera is now perfectly still (removing drift makes the scene feel notably more static)
    - FAIL if: Drift is invisible, or too aggressive (consciously noticeable as shaking)

    **4. State-Driven Reframing (CAM-06):**
    - If a voice pipeline is connected: trigger speaking and observe camera distance
    - If no pipeline: this can only be verified if chatStatus is wired. Note if unverifiable.
    - PASS if: Camera subtly pushes in during speaking, eases back when speech ends
    - FAIL if: No visible movement, or movement is jarring/too large

    **5. Orbit Modes (CAM-04):**
    - With orbit="locked": try to drag/scroll on the canvas
    - PASS if: Camera does not move from user input at all
    - With orbit="constrained": drag to orbit, try to reach unflattering angles
    - PASS if: User can orbit within a comfortable range but cannot reach behind or below the avatar
    - With orbit="free": drag freely
    - PASS if: Unrestricted orbit in all directions

    **6. No Phase 16 Regression (CAM-07):**
    - Verify lighting rig looks correct (three-point: warm key, cool fill, rim)
    - Verify contact shadows appear grounded below the avatar
    - Verify DOF (if enabled) focuses on the avatar and refocuses during preset transitions
    - PASS if: All Phase 16 systems work identically to before AvatarCamera
    - FAIL if: Jitter, lag, missing shadows, DOF out-of-focus, or backdrop misalignment
  </how-to-verify>
