## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM → tool execute | `set_emotion` arguments are produced by a remote model and are untrusted input |
| app code → setEmotionHint | Public setter reachable from any app code outside the React tree |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-03 | Tampering | createEmotionTool execute, normalizeEmotionHint | mitigate | Strict case-sensitive allow-list over the 6 EMOTION_NAMES, Number.isFinite plus a [0,1] clamp on intensity, and a default of 0.7. Invalid input returns success:false without calling the setter. The raw LLM string never reaches `VRMExpressionManager.setValue`, because only keys from the internal EMOTION_EXPRESSION_MAP are written. |
| T-18-04 | Denial of Service | LLM spamming set_emotion | accept | Each call restarts a bounded 0.4s crossfade over at most 2 expression slots, with O(1) per-frame cost. No queue grows. |
| T-18-05 | Information Disclosure | emotionSystemPrompt | accept | Static, non-secret prompt text. It instructs the model not to verbalize the tool. |
</threat_model>
