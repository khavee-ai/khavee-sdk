<objective>
Redesign the Khavee admin Settings page and the Gutenberg block sidebar UI to match the approved before/after mockup, eliminating the reported confusion about which fields are the global/platform default vs a local custom override.

This makes the source of truth visible per field and gives an explicit override/custom escape hatch.

Output: A sectioned Settings page with per-field "Synced from Platform" pills + native override disclosures; a block sidebar with "Global default / Custom" segmented toggles fed by a newly-exposed `window.khaveeaiGlobalConfig`.
</objective>
