<objective>
Fix and extend the site-wide floating chat widget WITHOUT touching the inline
embed layout. Four scoped changes:
1. Remove the red unread-dot from the floating launcher.
2. Hide the chat show/hide toggle in the floating panel (mic-only ControlBar).
3. Move the floating panel's mic button from bottom-center to bottom-right of
   the avatar area (avoid colliding with the centered "Click to talk" CTA).
4. Add floating-widget-specific background + 3D-model-position settings
   (independently configurable from the inline embed's global visual config),
   wired end-to-end: admin Settings fields -> PHP option/render path ->
   camelCase JS config -> FloatingWidget's own avatar area + AvatarScene call.

Purpose: The floating widget currently reuses inline-embed chrome/config that
doesn't fit its fixed 360x520 panel; this makes it self-contained and separately
configurable.
Output: Updated FloatingWidget + ControlBar + CSS + config type; new floating_*
admin settings persisted, rendered, and flowing into the floating mount config.

CRITICAL SCOPE GUARD: Every change must be floating-widget-only. The inline
embed (AppRoot's non-floating branch in mount.tsx, mount.tsx's ControlBar call,
existing global bg_color/avatar_offset_x/y/avatar_scale behavior, render()'s
public_safe output) MUST remain byte-for-byte unchanged in behavior/appearance.
mount.tsx is NOT edited by this plan.
