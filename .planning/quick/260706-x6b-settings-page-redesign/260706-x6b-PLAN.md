<objective>
Redesign the Khavee WordPress admin Settings page (`wordpress-plugin/includes/Admin/SettingsPage.php`) — a pure presentation-layer pass. User feedback verbatim: "the uxui of setting page is ass. it looks not beautiful and hard to use." Three complaints to fix: (1) plain WP-default styling with no spacing/hierarchy; (2) fields stacked with no visual grouping; (3) the live avatar preview sits BELOW the Floating Widget fields, forcing a scroll to see the effect of edits.

Purpose: Make the settings page look like a branded product screen (flat purple `#6929ff` design language from `packages/wp-bundle/styles.css`) with card-grouped sections, and place the Floating Widget's live preview BESIDE its fields (sticky, no scroll).

Output: A restyled `SettingsPage.php` with (a) a scoped branded stylesheet, (b) always-expanded card-based sections for all 4 groups, (c) a two-column fields|sticky-preview layout for the Floating Widget section only. Every existing field name/id/sanitization and all live-preview JS wiring keeps working byte-for-byte unchanged.

Scope guardrail: ONLY `SettingsPage.php` (its PHP rendering + the CSS it emits). Do NOT touch `editor.js`, the Gutenberg block sidebar, `packages/wp-bundle/styles.css`, `Plugin.php`, `preview.ts`, `build.mjs`, or any floating-widget/camera-angle FUNCTIONALITY. No new npm deps, no new build step — the page's JS stays 100% `wp_add_inline_script()`.
</objective>
